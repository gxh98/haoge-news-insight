# 字段细则与字数算法

配合 `SKILL.md` 用。写卡片拿不准时翻这里；交付前跑 `scripts/validate_card.py`。

## 一、字数算法（先定死，否则天天吵）

**字数 = 非空白字符数，含标点。**

- 汉字、英文字母、数字、标点，各算 1 个
- 空格、换行、制表符不计
- **不区分中英文**：`AI` 算 2 字，`World Labs` 算 9 字（空格不计）

| 写法 | 字数 |
|---|---|
| `AMD今年赚了82亿美元。` | 14 |
| `World Labs 裁员 70 人` | 15（World=5, Labs=4, 裁=1, 员=1, 7=1, 0=1, 人=1） |

### 重要：括号关键词不计入字数

【核心梳理】每条形如 `1.（关键词）内容`，**只有括号之后的内容计入 30 字上限**。
关键词本身受另一条约束：2–6 字，起导读作用。

## 二、逐字段细则

### 【原文标题】

- **原样保留**：不改写、不翻译、不省略、不美化
- 若正文标题与页面标题不一致，用**正文标题**，并在卡片末尾注明
- 标题党标题也照抄——那是原文事实的一部分，判断放在洞见里说

### 【1个核心词】

- 2–8 字，**一个词**，无空格无标点
- 作用像索引：以后你搜这个词，能想起来这条新闻
- 优先从原文的关键概念里取，不要自造生僻词

| 好 | 差 | 为什么 |
|---|---|---|
| `模型洞察` | `AMD收购World Labs对AI芯片竞争格局的深远影响` | 超长，不是"词" |
| `空间智能` | `收购` | 太泛，当不了索引 |
| `效率登顶` | `AI 又赢了` | 含空格、带情绪 |

### 【一句话概括】

- ≤40 字，**只留主谓宾**，不带修饰
- 模板：`谁 + 做了什么 + 结果/代价`
- 不要形容词、不要评论、不要"据悉""值得关注"

- 好：`AMD以82亿美元收购World Labs，李飞飞出任首席科学家。`
- 差：`震惊！芯片巨头AMD豪掷82亿美元重磅收购李飞飞创办的明星AI公司，引发业界高度关注。`

### 【核心梳理】

- **2–4 条**，按新闻重要性取舍，**不硬凑**
- 格式：`序号.（关键词）内容`；关键词 2–6 字；括号后内容 ≤30 字
- 每条一行，覆盖不同侧面（事件 / 数字 / 人事 / 背景 / 风险），不要三条讲同一件事
- 只写原文有的，不补充背景知识

好例：

```
1.（交易规模）82亿美元全股票，较2月估值溢价62%
2.（人事安排）李飞飞任执行副总裁兼首席科学家，向苏姿丰汇报
3.（技术方向）World Labs约70人，主攻空间智能与3D世界模型
```

差例（三个毛病一次占全）：

```
1.（事件）AMD宣布收购一家AI公司，这家公司是做世界模型的，创始人很有名，交易金额很大
2.（补充）据悉AMD近年来在AI领域持续发力，先后收购了多家公司
3.（评论）这笔收购显示出AMD追赶英伟达的决心
```
→ 第 1 条超字数且堆信息，第 2 条是原文外的背景，第 3 条是评论不是事实。

### 【1个洞见】

- ≤35 字，一句话，**不展开论证**
- 回答"这件事还意味着什么"——向前看，找趋势
- 必须是原文**没有直接点明**的，但能从原文事实推出来

### 【1个反直觉洞见】

- ≤35 字，一句话
- 回答"什么判断与常识相反却成立"——向内翻，找悖论
- **自查**：把这句话反过来读，如果反过来才符合常识，那么它才是反直觉的
- 不是"换个说法的常识"：`企业要重视技术` 不是反直觉，`买模型团队不是为了用模型，是为了预知芯片需求` 才是

### 【1个底层规律】

- ≤35 字，格式 `理论名——一句话解释`
- 写的是**这一类问题**的机制，不是这条新闻
- 先想机制再找名字；找不到确切理论就给机制性概括，不硬套
- 判定标准：**能不能脱离本新闻复述出来？**

## 三、交付前自查清单

1. 【原文标题】是否与正文标题完全一致？
2. 【1个核心词】是否 2–8 字、是"一个词"？
3. 【一句话概括】是否 ≤40 字、去掉所有修饰？
4. 【核心梳理】是否 2–4 条？每条括号后 ≤30 字？四条是否讲了四件事？
5. 三条洞见是否各 ≤35 字、且互不重叠？
6. 【1个反直觉洞见】反过来读是否才符合常识？
7. 【1个底层规律】能否脱离本条新闻复述？
8. 事实层有没有混进原文没有的信息？
9. 末尾是否带了 `> 原文：<链接>｜<来源>｜<日期>`？

跑一遍脚本收尾：

```bash
python scripts/validate_card.py <卡片文件.md>
```

退出码 0 才算过关。
