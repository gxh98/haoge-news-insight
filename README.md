# 昊哥-读新闻拿观点

把一条新闻链接，压成一张能直接看懂的**认知卡片**。

不搬运信息，只做提炼、关联和规律挂靠。

> 本技能中文名：**昊哥-读新闻拿观点**。GitHub 仓库名 `haoge-news-insight` 仅为平台技术标识（GitHub 不支持中文仓库名），转载、收录、引用请以中文名为准。

## 为什么造它

我是个抖音博主，每天要大量阅读汽车行业和 AI 行业的新闻——读不完、记不住，还看不出新闻背后的东西。时间和准确性冲突，逼着我做了这个工具：一条新闻链接进去，一张高浓度认知卡片出来，核心梳理、洞见、反直觉洞见、底层规律全都有，脚本自动校验，不编造。

如果你也是每天要大量输入行业信息的博主或内容创作者（抖音、B站、小红书都一样），这个工具就是给你的。它也可以搭配 DeepSeek / ChatGPT 网页版使用：让模型先读原文、再搜几十篇同类报道交叉补充事实层，卡片会更扎实。

## 怎么用（10 秒版）

**不用装任何东西。** 打开 [`prompts/card-prompt.md`](prompts/card-prompt.md)，把里面整段复制进任意对话框（DeepSeek 网页版、ChatGPT、豆包都行），然后在末尾附上新闻链接 —— 完事。

```
<粘贴 prompts/card-prompt.md 全文>

链接：https://example.com/news/xxxx
```

如果你在用 DSH / Claude Code 这类有技能系统的环境，把它装成技能就行，说一句"帮我看看这条：<链接>"会自动触发。

## 它解决什么问题

你每天要看的新闻，真正花时间的不是"读"，而是：

- 读完记不住，一周后想不起来看了什么；
- 同一条新闻在不同平台反复出现，还是要重新读一遍；
- 知道"发生了什么"，但不知道"这意味着什么"；
- 存了一堆链接，从来没回看过。

这个技能把"一分钟读完重点 + 多一层认知 + 能被检索"固定成一张**固定 7 字段的卡片**，每次输出结构完全一致，方便你横向对比、长期归档。

核心信条（源自万维钢）：**世间之事不是无限的，而是有限的。** 任何一条新闻，大概率是别人早已研究过的一大类事物中的一个例子。理解一件事，不是感叹它，而是找到它背后那个**可复用的机制**。

## 主要功能

- **固定 7 字段输出**：【原文标题】【1个核心词】【一句话概括】【核心梳理】【1个洞见】【1个反直觉洞见】【1个底层规律】
- **字数硬约束 + 机器校验**：`scripts/validate_card.py` 逐项检查字段、字数、条数、格式、感想类禁用词，不合格退出码非 0
- **事实层 / 推断层分离**：前四个字段只能来自原文，后三个允许推断但不得引入新事实 —— 这是防幻觉的底线
- **正文噪音切分**：新闻门户页面里"为你推荐"的其他新闻不会被当成本条事件写进卡片
- **降级策略**：付费墙、视频、只有标题、完全取不到，各自有明确处理方式，**取不到就直说，不编**
- **底层规律库**：`references/laws.md` 收录 6 类约 50 条机制（每条附适用信号与误用警告），让"向上抽"有落点而不是硬套
- **单文件提示词**：`prompts/card-prompt.md` 自包含，不依赖脚本，任何对话框都能用

## 常见问题（FAQ）

**Q：一定要装技能环境才能用吗？**
不用。把 `prompts/card-prompt.md` 全文粘进任意对话框（DeepSeek / ChatGPT / 豆包网页版都行）就能用；装成技能只是多了自动触发和脚本校验。

**Q：它会不会编造新闻内容？**
不会。事实层四个字段只能来自原文，推断层三个字段不得引入新事实；`scripts/validate_card.py` 逐项机器校验，取不到的直说，不编。

**Q：支持微信公众号、小红书链接吗？**
暂不支持专用解析。当前只处理普通网页新闻链接（噪音切分已覆盖新闻门户"推荐流"的陷阱）。

**Q：能处理付费墙和视频新闻吗？**
各自有明确降级策略——付费墙、纯视频、只抓到标题时，卡片会如实标注信息不足，绝不硬凑。

**Q：校验脚本报错怎么办？**
对照报错项改卡片即可：字段缺失、字数超限、感想类禁用词是三大常见项，退出码非 0 就是不合格。

## 暂不支持

- 不自动抓取：抓取交给宿主环境的联网能力（DSH 的 `web_fetch`、网页版内置联网），本技能只规定"怎么取、怎么切噪音、取不到怎么办"
- 不做公众号 / 小红书 / 微博的专用解析
- 不做新闻聚合推送（只处理你主动给的那一条）
- 不替你下投资或经营判断，只做结构化提炼
